Quick start (2 minutes)

  1. Install yt-dlp: python -m pip install -U yt-dlp
  2. Install ffmpeg (recommended for best merges/audio extraction).
  3. Paste a YouTube URL above and copy a command.
Why this architecture?

Direct browser-side downloading from YouTube is blocked by platform restrictions and CORS. This app focuses on a reliable command workflow that works locally and stays future-proof.
